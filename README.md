# 置換台

原文に規則を上から順にかける作業台です。正規表現、式、完全一致の辞書を、帳にまとめて保存できます。ブラウザの中だけで動き、帳は端末に残ります。

## 使い方

1. 原文を書く。
2. 規則を足す。パターン、フラグ、置換を書く。
3. 結果を見る。差分と、先頭の一致が規則の下に出ます。
4. 試験を足す。期待と結果が完全に同じとき合格です。

規則は帳に入ります。無効にした規則は飛ばします。壊れた規則があっても、その一つだけを飛ばして次へ進みます。

## 置換

いままでの `$1`、`$&`、`$<名前>` もそのまま使えます。

| 書き方 | 結果 |
| --- | --- |
| `$1:3` | `3` を `003` にする |
| `${桁($<n>, 3)}` | 同じ桁揃え |
| `${$<n> + 1}` | 名前付きグループを数として計算する |
| `$日付` `$時刻` `$日時` | そのときの日本時間 |
| `$回` | 何件目か |

空の置換は、一致した部分を消します。

## 辞書

規則ごとの置換辞書です。完全一致だけで、キーの一部や行の途中では置き換えません。

- **一致した全体**は `${辞書($&)}`
- **名前付きグループ**は `${辞書($<code>)}`
- 辞書に無いときは、取れた文字を残します。別の文字にするなら `${辞書($<code>, "無")}`
- **行を完全一致で探す**は、1行まるごとがキーの行だけを対象にします

`001` のようなゼロ付きのキーは、数値にせずそのまま引きます。

## 日本語と絵文字

パターンでは、次のような範囲をそのまま書けます。

```
あ-ん+
ア-ン
\p{ひらがな}
\p{絵文字}
```

## 持ち出し

- **XML** で規則を読み書きできます。
- 帳は JSON でも書き出せます。
- **共有** は規則を7日だけ預け、リンクには ID だけを渡します。

## 最初から入っている帳

| 帳 | 内容 |
| --- | --- |
| 日付を和式に | `2026-11-03` を `2026年11月03日` にする |
| 余白を畳む | 行の端と、連続する空白を畳む |
| タグを外す | HTML のタグを外す |
| かなと絵文字 | ひらがなを括り、絵文字を `★` にする |
| 辞書の完全一致 | 行と品番を、辞書の値に置き換える |
| 式で揃える | 桁、計算、通し番号、今日の日時 |
